# 🗓️ Employee Attendance & Leave Tracker — Excel Project

An Excel-based Employee Attendance and Leave Management System 
built to track daily attendance, manage leave balances, and 
visualize workforce data through an interactive dashboard.

---

## 📋 Features

- Employee Master with auto-generated Employee IDs
- 31-day monthly attendance tracking for all employees
- Drop-down attendance marking: Present, Absent, Leave, Holiday, Week Off
- Auto color coding — Green/Red/Yellow/Blue/Grey
- Leave balance auto-calculated from attendance data
- CL, SL, EL and LOP tracking per employee
- Live Leave Status — Healthy / Low / Critical / Exhausted
- Auto-updating Dashboard with KPI cards and charts
- Protected sheets to prevent accidental edits

---

## 📊 Dashboard Includes

- Total Employees KPI Card
- Average Attendance % KPI Card
- Total Leaves Used KPI Card
- Total LOP Days KPI Card
- Bar Chart — Employee-wise Attendance %
- Pie Chart — Leave Type Distribution
- Column Chart — Department-wise Attendance %

---

## 🛠️ Excel Skills Used

- COUNTIF, SUMIF, AVERAGEIF, COUNTA formulas
- Cross-sheet formula referencing
- Data Validation (Drop-down lists)
- Conditional Formatting (5 color rules)
- IF and nested IF formulas
- SUBSTITUTE and VALUE functions
- Chart creation and formatting
- Sheet Protection with password
- Freeze Panes
